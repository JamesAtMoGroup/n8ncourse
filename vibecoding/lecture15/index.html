CH 2-8 ✦ 部署上線 ⏱ 約 11 分鐘

技術方案｜部署——
把作品放上網路的常見做法

程式寫好了，下一步是讓別人也能用。了解部署流程、挑對平台，避開 AI 常推薦但對新手不友善的選項。

01

什麼是部署？

部署就是把做好的網頁或應用程式發布到網路上，讓其他人也能透過連結打開使用。在你自己電腦上跑得好好的，並不代表別人能看到——部署這一步，才算是真正「上線」。

🖱️
平台一鍵部署
應用程式生成平台通常有明顯的「Publish / 發布」按鈕，按下去就拿到連結
🔧
手動部署
用 AI 程式工具寫出來的程式，需要自己上傳程式碼、選平台、做設定，才能取得有效連結
💡 為什麼要提前決定部署方案？

不同平台的程式碼結構不太一樣。開發到一半才換平台，雖然 AI 可以幫你重寫，但過程不一定順。建議在動手寫程式之前，就先決定好要用哪個部署平台，或是先了解有哪些退路。

02

部署三步驟

不管用哪個平台，手動部署的流程基本上都一樣。搞懂這三步，後面再碰到任何平台都能觸類旁通。

🚀 部署流程
1
上傳程式碼——在本機測試完成後，把程式碼上傳到線上的版本控管空間（最常見的是 GitHub）。如果只是簡單的展示頁面，有時候也可以把內容整理成一個單一的 index.html，在上傳和管理上會比較直覺；但實際開發中，多數情況還是會把 HTML、CSS、JavaScript 分開管理。
2
設定部署平台——打開你選的部署服務，把 GitHub 上的儲存庫網址給它，告訴平台「我的程式碼在這裡」，然後做幾個基本設定（例如指定資料夾位置）。
3
取得網址——設定完成後等 1–3 分鐘刷新頁面，平台會自動生成一個可公開訪問的 URL。免費方案通常是一串較長的預設網址；想要自訂網域則需要另外購買。
💡 善用 AI 一步一步跟著做

每個部署平台在網路上都有充分的教學，你只需要對 AI 說：「我寫好了一個 index.html，我想用 GitHub Pages 部署，請你一步一步教我。」——AI 就會帶著你做完整個流程。

如果擔心 AI 教的是舊版操作，加一句「請參考最新版本的教學」，AI 就會優先依照最新資料來引導你，出錯的機率也會比較低。

💡 GitHub 是什麼？

可以把 GitHub 想成程式版的雲端硬碟，專門拿來放程式碼、追蹤修改記錄。上傳後會取得一個儲存庫網址（工程師常說 Repo），部署平台就是從這個網址去抓你的程式碼。

03

推薦的部署方案

以下四個方案對新手友善，都有免費額度可以起步。依照你的需求挑選就好，不需要全部都用。

平台 優點 限制 適合場景
Google Apps Script 免費、一鍵部署、可有前後端 無法放圖、無法自訂域名、綁 Google 生態系 企業內部小工具、試算表串接應用
GitHub Pages 免費、可傳圖、可自訂域名、可搭配 GAS 做後端 免費版儲存庫必須公開 個人網站、部落格、純前端小工具
Cloudflare Pages 免費版支援私有儲存庫、額外支援輕後端 功能較多、初次設定稍複雜 不想公開程式碼、需要輕量後端功能
Zeabur 有真正的後端與資料庫、付費方案友善（$5/月起） 服務選項多，第一次可能眼花繚亂 需要完整後端、資料庫的進階專案
💡 推薦的組合搭配

起步首選：Google Apps Script（功能夠用就留在這）

想要漂亮前端：GitHub Pages（前端）+ Google Apps Script（後端）

程式碼不想公開：改用 Cloudflare Pages 放前端

需要完整後端 / 資料庫：升級到 Zeabur

🤔 想一想

你目前在做或想做的專案，最後是要給自己用、給公司同事用，還是要公開給所有人？這個答案，可以幫你決定哪個平台最適合你。

04

AI 常推薦、但要小心的選項

當你在選部署平台的時候，建議你不要只看 AI 推薦什麼就去嘗試。因為 AI 通常會推薦在網路上討論度很高的工具，但這些工具不一定適合新手，而且它們可能有一些隱藏的門檻。

1
Vercel——免費方案有商業用途限制，不能商業使用，這是很多新手容易忽略的地方。
2
Render——如果服務在沒有人使用的時候就會進入休眠狀態，第一次打開就會比較慢。
3
GCP / AWS（Google Cloud、Amazon Web Services）——這些雲端平台是採用量方式計費，如果沒有特別注意，可能會產生額外費用。

但其實這些工具本身沒有不好，只是對於新手小白來說，可能會一個不注意就踩到一些不必要的雷。

⚠️ 注意

在新手階段，還是會建議你優先選擇「簡單、免費、限制清楚」的平台，先把整個流程走順，再來考慮進階工具。

05

想要自訂網址怎麼做？

部署平台預設會給你一串很長的網址。如果想要像 yourname.com 這樣簡潔的自訂域名，就需要另外向域名服務商購買。

.com
約 $11 美金 / 年
.tw
約 $23 美金 / 年
.ai
約 $70 美金 / 年
✓
Cloudflare Registrar（推薦首選）——價格透明、沒有隱藏費用。唯一的限制是支援的頂級域名較少，例如不支援 .tw。
✓
Gandi（次選）——支援的域名種類較多，包含 .tw。整體口碑不錯，定價合理。
✗
GoDaddy（不推薦）——廣告預算充足，搜尋時很容易跳出來，但行銷方式不太誠實：首年超低價，續費可能貴很多，還有許多你其實不需要的加購項目。建議避開。
💡 買完域名之後

域名買好後，需要在域名服務商和部署平台兩邊各做一些設定。步驟看起來多，但全程都可以叫 AI 一步一步帶你做——有印象知道這個流程存在，需要時再回來查就好，不需要現在就全部記住。
