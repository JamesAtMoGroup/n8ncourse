Markdown：
AI 看得懂的特殊符號

學會這些符號，你就能用更少的字，讓 AI 更精準地理解你的意思。不需要死記，用幾次就自然記住了。

01

Markdown 是什麼？為什麼要學？

Markdown 是一種格式語言——用特定符號表示文字的結構和意義，例如標題、清單、程式碼。AI 已完整學會這套語言，在指令裡用 Markdown，AI 讀得更快、理解得更準。

💡 一句話理解

就像中文的標點符號——不用也能看懂，但加上了，閱讀效率和理解準確度都大幅提升。Markdown 對 AI 的作用，就是這樣。

不要被「格式語言」嚇到。Markdown 就是幾個你鍵盤上本來就有的符號——#、-、```，被大家約定好了特定意義，全世界都這樣用。

02

常用的 Markdown 符號

# ## ### 標題層級
井字號代表標題。一個 # 是最大標題，兩個是次標題，三個是小標題。用來讓指令裡的段落層次更清楚。
你輸入
# 大標題
## 次標題
### 小標題
AI 理解為
大標題次標題小標題
- * 1. 清單
- 或 * 開頭是無序清單；1.、2. 是有序清單。符號或數字後面必須加空格，且要用英文半形符號——中文符號 AI 可能無法解讀。
你輸入
- 項目 A
- 項目 B

1. 第一步
2. 第二步
AI 理解為
項目 A項目 B
1. 第一步2. 第二步
``` ``` 程式碼 ／ 資料區塊
三個倒引號（```）成對包住一段內容，告訴 AI：這是程式碼、資料或錯誤訊息，不是指令。貼程式碼或錯誤訊息給 AI 時，都用這個包起來。
你輸入
```
這裡是程式碼
或錯誤訊息
```
AI 理解為
這裡是程式碼
或錯誤訊息
💡 貼錯誤訊息時用 ``` 包起來，AI 就知道這是要修正的內容。
> 引用
>（大於號）開頭表示引用。標示「這段是貼進來的原始內容」，和指令做區隔。
你輸入
> 這是錯誤訊息
> 第二行

請幫我修正
AI 理解為
這是錯誤訊息
第二行
請幫我修正
--- 分隔線
三個減號（---）是分隔線。區隔指令與要被處理的資料，比倒引號好打，效果相似。
你輸入
幫我修正以下程式碼：
---
function hello() {
  consle.log("hi")
}
AI 理解為
幫我修正以下程式碼：（以下是要被處理的程式碼）
03

工程師慣例符號

除了 Markdown，還有幾個來自軟體工程慣例的符號，AI 也完全看得懂。

<變數>   {變數} Placeholder（佔位符）
角括號 < > 或花括號 { } 包住的內容，代表「這個位置之後會被實際的值取代」。AI 看到就知道這是待填入的變數。
你輸入
活動標題：<活動名稱>
寄件人：{負責人姓名}
AI 理解為
「活動名稱」和「負責人姓名」是待填入的變數，程式執行時從資料來源取值代入
<標籤> </標籤> XML 標籤
成對的標籤標記一段內容，告訴 AI 這段的性質是什麼。結尾標籤比開頭多一個斜線 /。角括號和 Placeholder 長得一樣，但 AI 會根據上下文判斷。
你輸入
<信件內容>
親愛的 {收件人}，
感謝您報名本次活動...
</信件內容>
AI 理解為
標籤之間的文字是「信件內容」的樣板，不是指令本身
鍵: 值 YAML 鍵值對
冒號 : 表示「名稱對應內容」的關係，左邊欄位名、右邊值。冒號後面一定要有空格，AI 才能正確解析。
你輸入
信件主旨: 活動報到提醒
收件人: {姓名}
活動日期: 2024/04/20
AI 理解為
三個欄位各自對應的值，結構清晰，AI 能精準區分每個欄位
04

組合技：混搭使用效果最好

跟以前寫程式不同，你不需要每個語法都精確無誤。把不同的符號混在一起用，只要上下文清楚，AI 就能正確理解。

✦ 組合技範例：YAML ＋ XML ＋ Placeholder
信件主旨: 活動報到提醒

<信件內容樣板>
親愛的 {姓名}，感謝您報名 <活動名稱>...
</信件內容樣板>
🔑 怎麼解讀這個組合技

YAML 冒號：標示欄位名稱與對應值。
Placeholder：標記哪些地方是待填入的動態變數。
XML 標籤：圈出「樣板內容」，和指令做區隔。

三個符號各司其職，組合起來用很少的字就能說清楚複雜需求。

💡 一句話理解

這些符號就像標點符號——不用也能溝通，但用了之後 AI 讀懂得更快更準。不需要完美，大致正確就能理解。

✦ 本章重點整理
  • Markdown 是 AI 完全看得懂的格式語言，用了能提升理解準確度。
  • # 標題、- 清單、``` 程式碼區塊、> 引用、--- 分隔線——五個最常用的 Markdown 符號。
  • <變數> / {變數} 是 Placeholder，告訴 AI「這裡之後會被取代」。
  • XML 標籤 <名稱>..</名稱> 用來圈出特定性質的內容區塊。
  • YAML 冒號 鍵: 值 是最快速標示欄位對應關係的方式。
