CH 2-6 ✦ API 串接 ⏱ 約 12 分鐘

API——跨應用程式、
串接時要用的東西

上集講了前端與後端怎麼溝通，這集聚焦讓它們互相說話的橋樑——API：它是什麼、怎麼串接，以及為什麼 API Key 要像密碼一樣保護好。

01

API 是什麼？先看看生活裡的它

其實 API 早就無所不在，只是你通常感覺不到它的存在。先看四個你每天都在用、背後都是 API 在運作的場景：

用 Google 帳號登入
在陌生網站點「用 Google 登入」，是 API 在背後把兩個服務串起來，不必再重新註冊。
行動支付結帳
在購物網站選行動支付付款，是 API 把付款服務接進來完成交易。
天氣 App 顯示即時溫度
App 上的溫度與降雨機率，是 API 從氣象資料庫把資料拿過來。
線上填表臨櫃馬上看到
你線上填的表單，臨櫃人員立刻查得到，是 API 把資料傳到後端系統同步。
💡 一句話收束

這些「理所當然」的體驗，背後幾乎都是 API 在串接不同的服務。你感覺不到它，正是因為它做得夠好。

那 API 到底是什麼？全名是 Application Programming Interface。你不用背英文，只要記住一個字——橋樑。

🌉 最終定義

API 就是讓兩個不同的軟體，可以互相溝通、交換資料的橋樑機制。像銀行 A 要跟銀行 B 對帳，中間需要一套雙方都遵守的規則與管道——這套規則與管道，就是 API。

02

API 的兩個層次

在不同情境下聽到「API」，指的可能是兩種不同層次的概念。分清楚，之後看文件、跟 AI 溝通都不會混淆：

抽象層次：API 作為技術
泛指「連接兩個不同軟體的橋樑機制」這種通用能力，讓它們互相溝通、交換資料。
具體層次：某服務的 API
指「用程式跟這個特定服務溝通的標準與規則」，例如某平台的 API 有自己的格式與限制。
🎯 本集聚焦

API 的形式有很多種，這集我們只專注在最常用到的 Web API——也就是透過網路，讓不同系統互相傳送資料的那一種。

03

串接 API 的三大步驟

想把兩個服務串起來，流程基本上都一樣。以下三步驟，搭配 AI 一起做，整個過程會順很多：

1
確認可行性
搜尋「服務名稱 + API Docs」，看有沒有官方文件。有文件就代表高機率可以串接——不用點進去細讀，看到就算數。
2
準備 API Key
去該服務的後台找「生成金鑰」的地方，通常叫 API Key 或 Token／Secret。不確定去哪找，直接叫 AI 一步一步帶你設定。
3
讓 AI 生成串接程式碼（神燈精靈）
把 API 文件交給 AI，請它一步一步教你、幫你寫串接的程式碼，再告訴你貼到哪裡。這步會來回幾次，有耐心就能搞定。
💡 工程師的實戰心法

先別管功能細節，確認資料有串起來最重要。可以先問 AI：「我可以透過這個服務的 API，拿到我資料庫裡的資料嗎？」如果 AI 反應正面，直接說「那你幫我串好吧」——它通常就會生成程式碼並告訴你下一步。記得一步一步來。

04

串接卡住了怎麼辦？

老實說，講起來輕鬆，實際串接常常會卡關——這裡先自嘲一下「站著說話不腰疼」。卡關的兩大主因：你在陌生的後台闖關，加上 AI 教的有時候是舊版的操作方式（軟體介面經常改版）。遇到卡關很正常，以下三個策略輪流試。

1
搜尋成功案例
搜尋「服務A + 服務B + 串接」，看有沒有中英文成功案例。有的話代表這條路是通的，只是今天 AI 生成的程式碼剛好有問題。
2
把 API 文件貼給 AI
直接去官方 API Docs 找對應段落，開啟翻譯，把你需要的那段貼給 AI，讓它依照正確的文件重新生成。
3
把程式碼範例貼給 AI
從成功案例裡找到程式碼（程式碼才是重點，不是文章），貼給 AI，請它改成你需要的格式，或一步一步帶你操作。
✦ 一條原則

失敗，就提供更多文件、更多範例給 AI。你給的線索越具體，AI 生成的程式碼就越可能成功。

05

API Key 安全守則

⚠️ 很重要，說三遍

API Key 就是密碼。是密碼。是密碼。所有你對密碼不該做的事，對 API Key 一樣不該做——別貼上網、別傳給別人、別放進會被別人看到的地方。

曾有知名第三方工具因為資安漏洞，洩露了大量用戶的 API Key，這些 Key 直通用戶帳號，造成數千萬美元的損失。一旦外洩會有多大損害，就看你的帳號多有價值。

1
隨時可以撤銷、換新的
只要覺得不安全，馬上去後台撤銷那組 Key、重新生成一組。這個操作很簡單，不用猶豫。
2
開發完成後移到安全位置
開發測試階段風險低，暫時直接寫在程式碼裡沒問題。但一旦完成，就請 AI 教你放到更安全的位置（例如 環境變數），再把原本那組 Key 撤銷換新。
3
給最小權限、設用量上限
建立 API Key 時，只給這次任務需要的權限，別開放所有功能；同時設定用量上限。這樣即使 Key 不幸外洩，損失也在控制範圍內。
✦ 一句話記住

把 API Key 當成你家鑰匙——能換鎖就換鎖、平常收好、別給不必要的人。

✦ 本章重點整理

  • 串接三步驟：確認有 API Docs → 取得 API Key → 讓 AI 一步步生成串接程式碼
