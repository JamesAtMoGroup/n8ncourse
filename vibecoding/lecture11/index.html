程式語言：
每個平台都有最適合它的語言

看到一堆英文夾雜符號就頭大？這集帶你認識常見的程式語言，打破刻板印象——不是要你會寫，而是讓你跟 AI 協作時更有概念、更有效率。

01

為什麼要認識程式語言？

對程式碼有「對未知的恐懼」很正常——但只要對常見語言有基本認識，就能跨過這道心理門檻：

🎯 跟 AI 更精準溝通
給對關鍵字，對話不容易跑偏
🧠 知道能改、別動什麼
小修改自己來，不用浪費對話額度
⚡ 不再腦袋空空
從被 AI 支配變成有概念的指揮官
02

網頁御三家：HTML、CSS、JavaScript

你打開瀏覽器看到的任何一個網頁，背後都是由三種語言共同組成的：

HTML
結構 + 內容
就像角色的骨架
CSS
外觀 + 樣式
就像角色的皮膚衣服
JavaScript
行為 + 互動
就像角色的大腦
🛒 舉例：購物網站

HTML 標記哪是標題、按鈕、輸入欄位；CSS 決定顏色、字體、版面；當你按下「購買」按鈕時，JavaScript 負責跳轉到結帳視窗。三者缺一不可，共同組成完整的網頁體驗。

⚠️ 常見誤會：Java ≠ JavaScript

很多人以為 Java 就是 JavaScript 的簡稱——但其實它們完全是兩個語言，就像老婆餅裡面沒有老婆。

Java 語法嚴謹、有明確型別，早年是 Android 主力語言；JavaScript 靈活寬鬆、專為瀏覽器而生。歷史上先有 Java，JavaScript 取名只是當年蹭熱度，兩者沒有血緣關係。

📐 TypeScript = 嚴謹版 JavaScript（有親戚）

TypeScript 多了型別規範，讓程式碼結構更清晰，適合大型專案或多人協作。這幾年越來越流行，AI 也很擅長寫。不用特別學，知道它存在就好。

03

前端 vs 後端：誰負責什麼？

任何可以連上網路的應用程式，背後通常分成兩大部分：

FRONT-END
⬆ 前端 / 客戶端
就像餐廳的服務生——你看到菜單、點餐、上菜
畫面與互動
表單檢查
點擊後的視覺反應
BACK-END
⬇ 後端 / 伺服器端
就像餐廳的廚房——把食物做出來、處理訂單
接收請求、處理資料
資料庫互動
回傳結果給前端
🎟️ 例子：演唱會搶票

你在頁面上選座位、填資料——這些都是前端在處理。但你有沒有想過，為什麼同一張票不會被兩個人同時買走？這個把關的工作，就是後端在做的。前端讓你看得見、操作得了，後端讓資料不出錯、不重複。

🔌 怎麼判斷前端 vs 後端？

有一個很直覺的方法——把網路關掉：

✓ 還能看到、能用的 → 前端
✗ 需要網路才能完成的（登入、送單、載入資料）→ 仰賴後端

例外：計算機、PDF 閱讀器、轉檔工具 等本機 App，沒網路也跑得很好——它們沒有後端。

04

各平台對應的語言

不同平台用不同語言，知道目標平台 → 給 AI 精準的關鍵字就行，不用全背：

1
Web 前端HTMLCSSJavaScriptTypeScript
Chrome / Edge 外掛也屬於此類
2
iOS AppSwift
Apple 官方主推
3
Android AppKotlin
從 Java 演進，更現代
4
跨平台 AppReact Native (JS)Flutter (Dart)
RN 開發快、像做網頁；Flutter 滑感接近原生
5
桌面 AppSwift (Mac)C# (Windows)Electron (跨平台)
Electron 用網頁三本柱 HTML/CSS/JS，可跨 Mac+Windows
6
後端 / 伺服器Node.jsPythonPHP
後端的語言選擇最自由
🧱 框架（Framework）≠ 程式語言

像 React Native / Flutter / Electron 這些都不是「語言」，而是框架——就像蓋房子有現成的結構圖，你不用從骨架研究起，可以直接改造。框架幫你搭好基礎結構，你只需專注在功能上，大幅提升開發效率。

🌱 新手後端首推 Python 或 Node.js

Python 語法簡潔，AI 相關任務綜合能力最強；Node.js 用 JavaScript，前後端通用，學一個語言就能通吃。

🎯 不用背，有印象就好

聽了這麼多，是不是有點像劉姥姥逛大觀園？別擔心——不用把語言全背起來。當你確定了目標平台，腦袋裡會有模糊印象，想不起來搜尋一下，看到結果就會立刻記起來。這比一無所知再去搜尋要快得多。

✦ 本章重點整理
  • 認識降低恐懼——知道哪能改、哪別動，跟 AI 協作更有效率，不浪費對話額度
  • 網頁御三家：HTML（結構）/ CSS（外觀）/ JavaScript（互動）；Java ≠ JavaScript，老婆餅沒有老婆
  • 前後端判斷法：把網路關掉，還能看到的 = 前端；需要網路才能動的 = 後端
  • 平台對應語言：Web 三本柱 / iOS Swift / Android Kotlin / 後端 Python 新手友善
  • 框架 ≠ 語言：React Native、Flutter、Electron 都是框架，幫你搭基礎結構
