先決定平台：
手機、電腦、網頁⋯⋯我會在哪裡用這個程式？

開始寫程式前，你必須先知道它最終會跑在哪裡——因為不同平台，用的是完全不同的語言。

01

為什麼要先選平台？

你有一個想法，想把它做成一個程式——但在動手之前，第一個問題是：它要跑在哪裡？

平台不同，程式碼就長得不一樣。這就是為什麼你下載軟體時要選 macOS 版或 Windows 版；下載 App 要選 iOS 或 Android；甚至買遊戲，也分 Switch 或 PS5。它們的程式碼結構，可能是完全不同的東西。

💡 料理類比

同一道菜，在 氣炸鍋、電鍋、烤箱裡做，食材雖然相同，但步驟和時間完全不一樣。不先確認手邊的設備，就沒辦法選對做法。寫程式也一樣——不先確認平台，AI 也不知道該給你哪種程式碼。

02

常見的 5 種平台

除了電腦和手機，還有更多你可能沒想到的平台。以下是 5 個最常見的類型：

🖥️
桌機程式
安裝在電腦上執行，Windows 和 macOS 是兩套不同系統
📱
手機 App
iOS 與 Android 是兩套獨立系統，App 通常分開開發
🌐
網頁
用瀏覽器開啟，不需安裝，電腦手機都能用
🧩
瀏覽器外掛
加裝在 Chrome / Edge 上，擴充原有的瀏覽功能
💬
通訊軟體 Bot
在 Line、Discord、Slack 裡跑的自動化程式
🧩 瀏覽器外掛是怎麼來的？

翻譯外掛、截圖工具、廣告封鎖器，這些都是瀏覽器外掛。早期幾乎都是技術高手非法改寫瀏覽器才做到的，後來各大瀏覽器才開放合法的外掛機制。現在 Chrome 和 Edge 共用同一套標準，一個外掛就能橫跨兩個瀏覽器。

💬 通訊軟體也能跑程式？

Line、Discord、Slack 這類通訊軟體，允許你在裡面建立自動化的 Bot。你可以把行事曆、待辦清單或外部服務（像是線上的預約系統）串進聊天室，讓 Bot 自動提醒今天的行程、幫你翻譯訊息，甚至回覆常見問題。

03

網頁也分好幾種

網頁這個平台比較特別——它又可以細分成幾種類型：

Website
網站——偏向品牌形象頁或電商頁面，重視資訊的呈現。
Web App
網頁應用程式——互動感更強，更像桌機軟體搬進瀏覽器。例如 Canva、Notion、Figma。
📐 RWD ｜ Responsive Web Design

手機版和桌機版的網頁，有時會分開開發（Desktop Web / Mobile Web），但很多廠商會選擇用一套程式碼，讓網頁自動根據螢幕大小調整。這種方式叫做 RWD（響應式設計）——一份程式碼，自動適應所有螢幕。

🔍 動手試試：什麼是 RWD？
1
用瀏覽器開啟 YouTube
2
在頁面任意處按 右鍵 → 選「檢查」，進入開發者工具
（快捷鍵：Ctrl+Shift+I，Mac：⌘+Option+I）
3
點擊「切換裝置工具列」圖示，或按快捷鍵 Ctrl+Shift+M（Mac：⌘+Shift+M）
4
在右上角切換不同裝置尺寸，觀察網頁排版的變化——這就是響應式設計的實際效果
04

每個平台，都有最適合它的語言

不同平台的背後，跑的是不同的程式語言。你不需要親自學會這些語言，但知道自己的目標平台，就能給 AI 更精準的關鍵字，讓對話不容易跑偏、答案不容易離題。
